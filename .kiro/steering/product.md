# Product Overview

Vaimoz LivePilot is a full-stack live streaming automation platform that enables users to manage and automate live streams to platforms like YouTube.

## Core Features

- **Asset Management**: Upload and organize video/media assets from local storage or Google Drive
- **Campaign Management**: Create and configure streaming campaigns with RTMP or YouTube API integration
- **Stream Automation**: Schedule and run automated live streams using FFmpeg
- **Analytics & Monitoring**: Track stream performance, view logs, and monitor active streams
- **Playlist Management**: Organize assets into playlists for sequential streaming

## Target Use Case

Automated 24/7 live streaming for content creators who want to continuously broadcast pre-recorded content to YouTube or other RTMP-compatible platforms.

## Key Technologies

- FFmpeg for video processing and streaming
- YouTube Data API v3 for OAuth and stream management
- SQLite for local data persistence
- JWT authentication for user sessions
